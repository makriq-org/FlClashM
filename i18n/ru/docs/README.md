# 📚 Документация FlClashM

Добро пожаловать в справочник по **FlClashM** — Android-клиенту для `mihomo`, который прячет несколько инструментов обхода блокировок за одной кнопкой.

Документация разделена на две части: **руководство пользователя** — если вы настраиваете профиль и хотите, чтобы всё просто работало, и **раздел для разработчиков** — если вы собираете приложение, синхронизируете форк или разбираетесь в его устройстве.

> 🌍 Языки: **Русский** (канонический) · [English](../../en/docs/README.md) · [中文](../../zh/docs/README.md) · [فارسی](../../fa/docs/README.md)
>
> Русская версия обновляется первой. Переводы могут немного отставать — при расхождениях ориентируйтесь на русский текст.
