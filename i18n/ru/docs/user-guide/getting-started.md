# Начало работы

## Установка

1. Откройте выпуск в
   [SourceForge](https://sourceforge.net/projects/flclashm/files/releases/) или
   [GitHub Releases](https://github.com/makriq-org/FlClashM/releases/).
2. Для большинства современных устройств выберите
   `FlClashM-android-arm64-v8a.apk`. Если ABI неизвестен, используйте
   `FlClashM-android-universal.apk`.
3. Разрешите установку из выбранного источника в настройках Android и установите
   APK. AAB предназначен для магазинов и напрямую не устанавливается.

Обновление должно иметь ту же Android-подпись, что и установленная версия. Если
система сообщает о конфликте подписи, не удаляйте приложение автоматически:
удаление также удалит его локальные данные. Сначала проверьте источник APK.

## Добавление профиля

Добавьте конфигурацию по URL, из YAML-файла или QR-кода. FlClashM поддерживает
обычные профили Mihomo; поля расширений нужны только для встроенных узлов и
управления Android-приложениями.

URL подписки и профиль могут содержать секреты. Не вставляйте их в публичные
issues. Провайдеру достаточно отдавать YAML с корректным MIME/текстовым ответом;
большинство дополнительных заголовков влияет на отображение, а
`profile-update-interval` и `flclashm-newdomain` управляют будущим refresh по
правилам из [описания provider metadata](provider-hints.md).

## Первое подключение

1. Выберите добавленный профиль и дождитесь его проверки.
2. Нажмите переключатель подключения.
3. Подтвердите системный запрос Android на создание VPN.
4. Если профиль содержит встроенный узел, дождитесь подготовки процесса. При
   обязательной connectivity-проверке ошибка отменит запуск и вернёт прежний
   рабочий план.

TUN на Android включается политикой приложения. Профильные
`include-package`/`exclude-package` имеют приоритет над ручным списком контроля
доступа; экран приложений показывает этот режим как управляемый профилем.

## Обновления

Встроенный апдейтер проверяет подписанный каталог, SHA-256 выбранного APK и затем
передаёт файл системному установщику Android. По умолчанию показываются только
стабильные версии; предварительные включаются отдельно в настройках.

Если автоматическая установка недоступна, скачайте APK того же канала вручную из
официального хранилища и установите поверх текущей версии. Понижение версии может
быть заблокировано Android и защитой каталога обновлений.

## Если подключение не запускается

- Проверьте сообщение валидатора профиля: неизвестные поля встроенного узла
  отклоняются намеренно.
- Убедитесь, что сервер, комната и ключи профиля актуальны; FlClashM не выдаёт
  инфраструктуру встроенных узлов.
- Для OlcRTC в режиме `auto` проверьте, что узел напрямую входит в proxy group с
  доступным URL проверки. `activation: always` полезен для диагностики прежнего
  постоянного режима.
- Для ByeDPI отличайте временный fallback от проверенного кэша: подбор может
  продолжаться в фоне после подключения.
- В issue приложите очищенный debug-лог и точные шаги воспроизведения, но удалите
  URL подписки, пароли, ключи и токены.
