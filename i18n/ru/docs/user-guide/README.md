# Руководство пользователя

FlClashM выпускается для Android и работает с обычными профилями Mihomo, а также
с расширениями для встроенных узлов и пакетной маршрутизации.

1. [Установите приложение и добавьте профиль](getting-started.md).
2. Если профиль использует `type: byedpi`, `type: olcrtc` или
   `type: naiveproxy`, проверьте [схему встроенных узлов](profiles.md).
3. Если профиль управляет Android-приложениями через секцию `tun`, используйте
   [описание раздельного туннелирования](split-tunneling.md).
4. Провайдерам подписок доступны безопасные
   [подсказки отображения](provider-hints.md).

## Что хранить в секрете

Профиль может содержать пароли NaiveProxy, ключ OlcRTC, токены подписки и адреса
частных сервисов. Перед публикацией issue или лога удаляйте эти значения, URL
подписки и заголовки авторизации. Для диагностики обычно достаточно версии
приложения, модели и версии Android, шага сбоя, текста ошибки и очищенного
фрагмента конфигурации.

## Каналы выпуска

Стабильный канал подходит для обычной установки. Предварительный канал включается
явно в настройках обновления и предназначен для проверки ещё меняющегося
контракта. APK публикуются в основном хранилище
[SourceForge](https://sourceforge.net/projects/flclashm/files/releases/) и
зеркалируются в [GitHub Releases](https://github.com/makriq-org/FlClashM/releases/).
