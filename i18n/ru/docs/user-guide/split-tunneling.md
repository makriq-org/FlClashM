# Раздельное туннелирование

FlClashM позволяет управлять тем, какие приложения используют VPN, а какие нет. Это можно задать двумя способами: вручную в настройках приложения или прямо в YAML-профиле.

## Раздельное туннелирование через профиль

Провайдер может задать правила раздельного туннелирования прямо в профиле. Эти правила имеют приоритет над ручными настройками пользователя.

### Whitelist: только выбранные приложения

```yaml
tun:
  enable: true
  include-package:
    - org.telegram.messenger
    - com.termux
```

Только указанные приложения будут использовать VPN.

### Blacklist: исключить выбранные приложения

```yaml
tun:
  enable: true
  exclude-package:
    - com.android.chrome
    - org.mozilla.firefox
```

Указанные приложения не будут использовать VPN.

> Нельзя использовать `include-package` и `exclude-package` одновременно.

## Форматы селекторов

Помимо точных имён пакетов, поддерживаются маски и регулярные выражения:

| Формат | Пример | Описание |
|--------|--------|----------|
| Точное имя | `com.termux` | Точное совпадение |
| Маска | `*.yandex.*` | Все приложения Яндекса |
| Регулярное выражение | `re:^org\.mozilla\..+$` | Все приложения Mozilla |
| Исключение | `!ru.yandex.browser` | Исключить из списка |

### Пример с масками и исключениями

```yaml
tun:
  enable: true
  exclude-package:
    - '*.yandex.*'              # Все приложения Яндекса
    - '!ru.yandex.browser'      # Кроме Яндекс.Браузера
    - 're:^org\.mozilla\..+$'   # Все приложения Mozilla
```

## Загрузка списков из файлов

Списки пакетов можно вынести в отдельные файлы:

```yaml
tun:
  enable: true
  include-package-file:
    - lists/allowed-apps.txt
```

Файлы должны содержать по одному имени пакета или селектору на строку.

## Загрузка списков из URL

Списки можно загружать по HTTP(S):

```yaml
tun:
  enable: true
  include-package-url: https://example.com/packages.txt
```

Список кэшируется локально и используется при недоступности URL.

## Как это работает

1. FlClashM читает секцию `tun` из профиля.
2. Разрешает селекторы (маски, regex) в конкретные установленные пакеты.
3. Создаёт правила контроля доступа.
4. Эти правила имеют приоритет над ручными настройками.

Если профиль задаёт раздельное туннелирование, в настройках приложения будет показано, что контроль доступа управляется профилем.
