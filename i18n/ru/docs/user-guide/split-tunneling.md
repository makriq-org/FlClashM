# 🎯 Раздельное туннелирование

Раздельное туннелирование решает простой вопрос: **какие приложения ходят через VPN, а какие — напрямую**. Настроить это можно двумя способами:

- 🖐 **вручную** — в настройках приложения;
- 📄 **через профиль** — правила задаёт провайдер прямо в YAML.

> ℹ️ Правила из профиля имеют **приоритет** над ручными настройками. Если профиль задаёт раздельное туннелирование, в настройках приложения будет показано, что контроль доступа управляется профилем.

---

## 📄 Настройка через профиль

Правила живут в секции `tun`. Есть два взаимоисключающих режима.

### ✅ Whitelist — только выбранные приложения

Через VPN идут **только** перечисленные приложения, всё остальное — напрямую.

```yaml
tun:
  enable: true
  include-package:
    - org.telegram.messenger
    - com.termux
```

### ⛔ Blacklist — исключить выбранные приложения

Через VPN идёт **всё, кроме** перечисленного.

```yaml
tun:
  enable: true
  exclude-package:
    - com.android.chrome
    - org.mozilla.firefox
```

> ⚠️ `include-package` и `exclude-package` **нельзя** использовать одновременно.

---

## 🧬 Форматы селекторов

Помимо точных имён пакетов поддерживаются маски и регулярные выражения:

| Формат | Пример | Что означает |
|--------|--------|--------------|
| 🎯 Точное имя | `com.termux` | Точное совпадение пакета |
| ✳️ Маска | `*.yandex.*` | Все приложения Яндекса |
| 🔤 Регулярка | `re:^org\.mozilla\..+$` | Все приложения Mozilla |
| 🚫 Исключение | `!ru.yandex.browser` | Убрать из списка |

Их можно комбинировать — например, «весь Яндекс, кроме Браузера, плюс всю Mozilla»:

```yaml
tun:
  enable: true
  exclude-package:
    - '*.yandex.*'              # Все приложения Яндекса
    - '!ru.yandex.browser'      # Кроме Яндекс.Браузера
    - 're:^org\.mozilla\..+$'   # Все приложения Mozilla
```

## 📥 Списки из файлов и URL

Длинные списки удобно вынести наружу — по одному имени пакета или селектору на строку.

**Из файла:**

```yaml
tun:
  enable: true
  include-package-file:
    - lists/allowed-apps.txt
```

**Из URL по HTTP(S):**

```yaml
tun:
  enable: true
  include-package-url: https://example.com/packages.txt
```

> 💾 Список по URL кэшируется локально и используется, если адрес окажется недоступен.

## ⚙️ Как это работает под капотом

1. 📖 FlClashM читает секцию `tun` из профиля.
2. 🔎 Разрешает селекторы (маски, regex) в конкретные установленные пакеты.
3. 🧱 Создаёт правила контроля доступа.
4. 🏆 Эти правила получают приоритет над ручными настройками.
