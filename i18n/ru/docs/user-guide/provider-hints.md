# 🎨 Подсказки провайдера

Провайдер может прислать в заголовках ответа подписки набор подсказок с префиксом `flclashm-*` или совместимым с FlClashX префиксом `flclashx-*`. Если присутствуют оба варианта одного заголовка, FlClashM использует `flclashm-*`.

## 🔧 Как это работает

Подписка отдаёт YAML-профиль в теле ответа, а в HTTP-заголовках — подсказки. FlClashM применяет их при добавлении или обновлении профиля (см. [`flclashm-custom`](#-поведение)).

> ℹ️ Значения ряда заголовков закодированы в **base64** (это помечено ниже). Булевы заголовки принимают `true`/`false`.

---

## 🖌 Оформление

| Заголовок | Значение | Что делает |
|-----------|----------|-----------|
| `flclashm-background` | URL | Фоновое изображение |
| `flclashm-hex` | `HEX[:вариант][:pureblack]` | Цветовая тема (см. ниже) |

### Формат `flclashm-hex`

- **`HEX`** — цвет: 6 или 8 hex-символов, с `#` или без (`5c6bc0`, `#5c6bc0`). 8 символов — с альфа-каналом.
- **`вариант`** *(необязательно)* — имя схемы Material 3: `tonalSpot`, `fidelity`, `monochrome`, `neutral`, `vibrant`, `expressive`, `content`, `rainbow`, `fruitSalad`.
- **`pureblack`** *(необязательно)* — чисто-чёрный фон (удобно для OLED).

```text
flclashm-hex: 5c6bc0                    # только цвет
flclashm-hex: #5c6bc0:vibrant           # цвет + схема
flclashm-hex: 5c6bc0:vibrant:pureblack  # цвет + схема + чёрный фон
```

## 🏠 Главный экран

| Заголовок | Значение | Что делает |
|-----------|----------|-----------|
| `flclashm-widgets` | список | Порядок и набор виджетов дашборда |
| `flclashm-view` | `ключ:значение;…` | Вид страницы узлов (см. ниже) |
| `flclashm-newboard` | `true`/`false` | Включить новую панель («Новый вид») |
| `flclashm-denywidgets` | `true`/`false` | Запретить редактирование главного экрана |

### Формат `flclashm-view`

Пары `ключ:значение` через `;`. Любой ключ необязателен — задавайте только нужные.

| Ключ | Допустимые значения |
|------|---------------------|
| `type` | `list`, `tab` |
| `sort` | `none`, `delay`, `name` |
| `layout` | `loose`, `standard`, `tight` |
| `icon` | `icon` (или `standard`), `none` |
| `card` | `expand`, `shrink`, `min`, `oneline` |

```text
flclashm-view: type:tab;sort:delay;card:min
```

## 🏷 Сведения о сервисе

> 🔐 Значения этих трёх заголовков передаются в **base64**.

| Заголовок | Значение | Что делает |
|-----------|----------|-----------|
| `flclashm-servicename` | base64 | Название сервиса |
| `flclashm-servicelogo` | base64 (URL) | Логотип сервиса |
| `flclashm-serverinfo` | base64 | Имя группы с информацией о сервере |
| `flclashm-buyplan` | URL | Ссылка для продления подписки |
| `flclashm-buytraffic` | URL | Ссылка для покупки трафика |

## ⚙️ Настройки

| Заголовок | Значение | Что делает |
|-----------|----------|-----------|
| `flclashm-settings` | флаги через запятую | Предзаполнить настройки приложения |
| `flclashm-globalmode` | `false` скрывает | Показывать ли выбор глобального режима (по умолчанию показан) |
| `flclashm-androidsecure` | `true` | Отключить `mixed-port` на Android, не меняя режим VPN |

### Флаги `flclashm-settings`

| Флаг | Что включает |
|------|--------------|
| `autostart` | Автозапуск/автоподключение (в т. ч. после перезагрузки) |
| `autoupdate` | Автоматическую проверку обновлений |
| `autorun` | Запуск приложения при старте системы *(desktop)* |
| `shadowstart` | Тихий (фоновый) запуск |
| `minimize` | Сворачивание в трей при выходе *(desktop)* |

```text
flclashm-settings: autostart,autoupdate
```

> 🏆 `flclashm-settings` применяется, **только если пользователь не переопределил** настройки провайдера вручную. Ручной выбор пользователя всегда важнее.

---

## 🔁 Поведение

| Заголовок | Значение | Что делает |
|-----------|----------|-----------|
| `flclashm-custom` | `add` / `update` | Когда применять оформление |

- **`add`** — только при **добавлении нового** профиля.
- **`update`** — при **каждом обновлении** профиля.
- Любое другое значение (или отсутствие) — оформление не применяется.

В YAML-группе `GLOBAL` также поддерживаются поля `flclashm-override` и `flclashx-override`. При наличии обоих используется `flclashm-override`.

---

## 📣 Стандартные заголовки подписки

Помимо `flclashm-*` приложение распознаёт привычные заголовки панелей:

| Заголовок | Что делает |
|-----------|-----------|
| `announce` | Объявление в приложении (поддерживает `base64:`-префикс) |
| `support-url` | Ссылка на поддержку |
| `x-hwid-max-devices-reached` | Уведомление о превышении лимита устройств |
| `x-hwid-not-supported` | Уведомление о неподдерживаемом HWID |

---

## 🚧 Границы

- 💡 Подсказки носят **рекомендательный** характер.
- 🔒 `androidsecure` может только отключить локальный входящий порт; режим VPN остаётся выбором пользователя.
- 🏆 Настройки пользователя важнее рекомендаций провайдера.
