# Подсказки провайдера

Провайдер может передавать в заголовках подписки подсказки с префиксом `flclashm-*`. Они влияют на оформление и поведение приложения, но не могут ослаблять защиты.

## Как это работает

Подписка отдаёт YAML-профиль в теле ответа, а в заголовках — подсказки. FlClashM применяет их при добавлении или обновлении профиля.

## Доступные заголовки

### Оформление

| Заголовок | Описание |
|-----------|----------|
| `flclashm-background` | Фоновое изображение |
| `flclashm-hex` | Цветовая схема |

### Главный экран

| Заголовок | Описание |
|-----------|----------|
| `flclashm-widgets` | Порядок виджетов |
| `flclashm-view` | Вид страницы узлов |
| `flclashm-denywidgets` | Запрет редактирования главного экрана |

### Сведения о сервисе

| Заголовок | Описание |
|-----------|----------|
| `flclashm-servicename` | Название сервиса |
| `flclashm-servicelogo` | Логотип сервиса |
| `flclashm-serverinfo` | Информация о сервере |

### Настройки

| Заголовок | Описание |
|-----------|----------|
| `flclashm-settings` | Автозапуск и проверка обновлений |
| `flclashm-globalmode` | Видимость выбора режима |

### Поведение

| Заголовок | Описание |
|-----------|----------|
| `flclashm-custom` | Когда применять оформление: `add` или `update` |

## Границы

- Подсказки носят рекомендательный характер.
- Они не могут изменять защиты Android или политику безопасности.
- Пользовательские настройки важнее рекомендаций провайдера.
