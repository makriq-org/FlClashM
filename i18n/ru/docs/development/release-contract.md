# 📦 Релизы

## 🏷 Правила версий

| | Формат |
|---|--------|
| **Стабильная версия** | `MAJOR.MINOR.PATCH+versionCode` |
| **Предварительная версия** | `MAJOR.MINOR.PATCH-preN+versionCode` |
| **Тег** | точное `v<versionName>` |
| **`applicationId`** | `com.makriq.flclash` |

Полный `versionName`, включая `-preN`, хранится в `pubspec.yaml`. CI не подменяет его
при сборке, а тег обязан совпадать с ним после добавления префикса `v`.

При синхронизации с FlClashX изменения апстрима тоже учитываются при выборе уровня повышения версии по
их эффекту для пользователей FlClashM. Версию FlClashX в `versionName` форка не
переносим.

## 📂 Состав релиза

- `FlClashM-android-universal.apk`
- `FlClashM-android-arm64-v8a.apk`
- `FlClashM-android-armeabi-v7a.apk`
- `FlClashM-android-x86_64.apk`
- `FlClashM-android-release.aab`

> [!IMPORTANT]
> Каждый релиз содержит `.sha256` для каждого файла. Для стабильного релиза их наличие дополнительно считается **обязательной частью** выпускного контракта.

## 📥 Доставка обновлений приложения

SourceForge `flclashm` — **основной** канал доставки APK, GitHub — **запасной**. Приложение читает фиксированные указатели:

- `https://flclashm.sourceforge.io/update/stable.json`
- `https://flclashm.sourceforge.io/update/pre.json`

Для каждого указателя рядом публикуется двоичная подпись `.sig`. Подпись проверяется встроенным открытым ключом **Ed25519 до разбора JSON**. Каталог содержит SHA-256 и упорядоченный список зеркал каждого ABI APK. Заголовки поставщика для определения доверия **не используются**.

Файлы выпуска сначала загружаются в неизменяемый каталог `releases/<tag>`. Затем публикуется подпись указателя и **последним** — сам указатель.

> [!IMPORTANT]
> Для выпуска нужны секреты `APP_UPDATE_SIGNING_KEY`, `SOURCEFORGE_SSH_KEY` и `SOURCEFORGE_USERNAME`.

## ⏮ Откат

Приложение запоминает наибольшие `versionCode` и время публикации **отдельно для каждого канала** и отвергает повтор старого подписанного каталога. Поэтому:

- откат выполняется **только новым исправляющим выпуском** с большим `versionCode`;
- уже установленный APK также нельзя понизить средствами Android;
- при смене ключа каталога сначала выпускается **переходная** версия приложения с новым открытым ключом.
