# Политика безопасности

## Базовый принцип

Политика безопасности определяется клиентом, а не провайдером.

**Провайдер может:**
- передавать метаданные;
- подсказки оформления;
- рекомендательные настройки.

**Провайдер не может:**
- ослаблять защиты клиента;
- задавать обязательное поведение через заголовки.

## Защиты Android

- TUN принудительно включается
- Раздельное туннелирование из профиля имеет приоритет
- Индикатор применённых пакетных правил читает снимок Android VPN-службы, а не
  текущую конфигурацию ядра
- Загрузчик обновлений проверяет SHA256
- Встроенные узлы не могут задавать локальные адреса и порты
- `olcrtc` работает только в режиме CNC
- В `olcrtc profiles[]` рекурсивно запрещены `socks.host`, `socks.port` и `crypto.key_file`; остальные поля прозрачно передаются OlcRTC
- `byedpi` проверяет только указанные URL

## Заголовки провайдера

- Заголовки `flclashm-*` остаются рекомендательными
- Оформление не может менять защиты среды выполнения
