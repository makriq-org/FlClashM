# Go backend

Обзор слоёв — в [архитектуре](../architecture.md), команды проверки — в
[verification.md](../verification.md).

## Размещение

`core/backend/**` не зависит от Flutter, JNI или Android и проверяется на хосте.
`core/backend_host.go` подключает настоящий mihomo, внешние процессы и Android.

| Пакет | Назначение |
|---|---|
| `backend` | RuntimeCoordinator, неизменяемый план, очередь команд и восстановление |
| `backend/service` | API приложения, операции, настройки, резервные копии и уведомления |
| `backend/profiles` | Каталог профилей, исходники, миграция и подписки |
| `backend/compile` | Разбор профиля, JS, внешние узлы, списки приложений и SecurityPolicy |
| `backend/transport` | Процессы узлов, SOCKS-проверки и кэши |
| `backend/host` | Отменяемые запросы к платформе |
| `backend/netpolicy` | Проверка адресов публичных списков и пробных запросов |

Flutter отправляет действия через `lib/product/backend/**`. Android `BackendHost`
открывает backend в `:remote`; `RemoteService` передаёт Binder-запросы.
Отключение UI не останавливает backend, подписки или подключение.

## Подготовка плана

Компилятор получает исходник и metadata профиля, настройки и возможности платформы.
Он сохраняет семантику YAML/JSON, порядок групп, GLOBAL override и JS `main(config)`.
JS работает в отдельной Goja VM с отменой и лимитом времени, без доступа к host API.

SecurityPolicy применяется до проверки движком. Она ограничивает mixed-port и
режим global по заголовкам провайдера, формирует split tunneling и исключает
собственные пакеты из VPN. Пользовательский выбор режима VPN сохраняется.
Android Builder применяет готовый результат без собственной бизнес-политики.

Полная проверка mihomo на Android выполняется в `:validator`, поскольку parser
меняет глобальные настройки процесса. Временный файл приватен; отмена завершает
валидатор и отбрасывает поздний ответ.

RuntimePlan содержит версию, монотонное поколение и SHA-256 содержимого.
Его представление закрыто, наружу возвращаются копии. При чтении проверяются
версия и digest. Клиент не может передать произвольный исполняемый план.

## API и события

API, данные и план версионируются отдельно; текущая версия каждого — `1`.
Запрос содержит `apiVersion`, `operationId`, `method`, `params`.
Ответ содержит `result` либо `error`.

| Методы | Назначение |
|---|---|
| `snapshot`, `runtime.view`, `presentation` | Каталог, runtime и готовые данные для UI/Android |
| `runtime.start/stop/apply/restart/recover/toggle` | Управление подключением |
| `operation.get/cancel` | Результат или явная отмена операции |
| `settings.patch`, `profile.*`, `subscription.refresh`, `proxy.select` | Изменение исходных данных |
| `backup.export/restore`, `blob.*` | ZIP и передача больших файлов через Binder |
| `engine.command` | Сериализованные команды соединений, providers и geo |
| `ui.attach`, `data.reset` | Открытие UI и сброс данных |

Повтор операции с тем же ID и содержимым возвращает прежний результат; другое
содержимое с тем же ID отклоняется. Операция может вернуть `runtimeOperationId`:
клиент ожидает и доменное изменение, и связанное применение runtime.
Timeout ожидания, отключение или смерть Flutter не отменяют операцию.

События имеют `instanceId` и sequence. Медленный подписчик не блокирует VPN;
переполнение требует нового снимка. Flutter подписывается до чтения снимка и
отбрасывает устаревшие события. При смерти backend меняется `instanceId`.
При работающем VPN UI показывает применённый выбор прокси из `runtime.view`,
чтобы не выдавать неудачное переключение за действующее.

## Состояние и восстановление

- **Desired** — сохранённое намерение пользователя. Stop записывается до эффектов.
- **Applied** — последний полностью подтверждённый план и состояние узлов.
- **Observed** — фактическое состояние движка и платформы. Ошибка наблюдения
  означает «неизвестно», а не успешный запуск или остановку.

`backend-v1.json` хранит намерение, поколение, применённый input/plan, журнал
незавершённого перехода и ограниченную историю результатов. Запись использует
atomic rename и fsync файла и каталога. После открытия незавершённые операции
получают статус interrupted. Восстановление использует последний подтверждённый
input и тот же путь компиляции/исполнения, что обычный запуск.

Подготовка ограничена одним слотом и отделена от эффектов. Stop отменяет её,
не дожидаясь некооперативного parser. Проверки поколения и context не дают
устаревшему результату примениться. При ошибке перехода восстанавливается
подтверждённый план; если это невозможно, ресурсы останавливаются.

Одинаковый план сохраняет службу и время запуска; явный restart перезапускает их.
Live settings и выбор прокси не пересоздают TUN без необходимости. Отзыв VPN
сохраняет Stop, в том числе при переходе в другой VPN-клиент. Позднее системное
восстановление не возобновляет отозванную сессию; новый явный Start разрешён.

OS-события имеют sequence и объединяются по виду. Сетевые проверки, screen/Doze,
сон резервных узлов и wakelock обрабатывает Go без UI. Android только передаёт
факты и предоставляет ресурсы. Foreground-ресурс на время подготовки привязан
к ID операции; поздний Intent или teardown не меняет новое намерение.

Внешний HTTP controller проверяет secret до передачи команд. Изменения config
и выбора проходят backend; произвольные config paths, upgrade и старые runtime
setters закрыты.

## Хранение и миграция

Каталог профилей хранит оригинальные исходники по хешу содержимого. Настройки и
metadata сохраняют неизвестные поля и большие целые. Проверка ревизий не даёт
поздней подписке или старому редактору перезаписать новое содержимое.

Миграция из SharedPreferences однократная: сохраняются IDs, даты и исходные байты.
После неё старые настройки не служат источником состояния. Некорректный профиль
остаётся доступен редактору, но не запускается. Отсутствующий URL-исходник
загружается отменяемой операцией; поздний ответ после Stop не включает VPN.

ZIP-резервная копия сохраняет `config.json`, исходники профилей и provider cache.
Отсутствующий исходник не заменяется пустым файлом. Проверяются traversal,
symlink и zip-bomb. Передача через Binder идёт блоками по 192 КиБ: не более
128 МиБ на файл, 32 незавершённых переносов и 512 МиБ суммарно.
DocumentsProvider не публикует внутренние журналы и исполняемые артефакты.

Удаление последнего профиля сначала сохраняет Stop. Reset останавливает runtime,
дожидается отмены подготовки, затем удаляет исходники, артефакты и переносы.
Маркер миграции и монотонность поколений сохраняются, поэтому старые данные
не появляются снова.

Go обновляет подписки и списки приложений без UI. Списки используют прежний кэш;
ошибка сети сохраняет последнюю копию, а без кэша не создаёт пустую политику.
Уведомления об истечении подписки сохраняют пороги 3/2/1/0 дней и «истекла»;
Go устраняет повторы, Android локализует показ.
