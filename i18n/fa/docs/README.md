# 📚 مستندات FlClashM

به مرجع **FlClashM** خوش آمدید — کلاینت اندرویدی `mihomo` که چند ابزار عبور از سانسور را پشت یک دکمه پنهان می‌کند.

مستندات به دو بخش تقسیم شده: **راهنمای کاربر** — اگر در حال تنظیم پروفایل هستید و می‌خواهید همه‌چیز به‌سادگی کار کند؛ و **بخش توسعه‌دهنده** — اگر برنامه را می‌سازید، fork را همگام می‌کنید یا در ساختار آن کاوش می‌کنید.

> 🌍 زبان‌ها: [Русский](../../ru/docs/README.md) (مرجع) · [English](../../en/docs/README.md) · [中文](../../zh/docs/README.md) · **فارسی**
>
> نسخهٔ روسی زودتر به‌روزرسانی می‌شود. ترجمه‌ها ممکن است اندکی عقب باشند — در صورت تردید، متن روسی معیار است.

---

## 🚀 راهنمای کاربر

چطور کاری کنیم که برنامه همان‌طور که می‌خواهید رفتار کند.

| بخش | دربارهٔ |
|-----|---------|
| 🧩 **[نودهای داخلی](user-guide/profiles.md)** | ByeDPI، OlcRTC و NaiveProxy مستقیم در پروفایل YAML |
| 🎯 **[تونل‌زنی جداگانه](user-guide/split-tunneling.md)** | کدام برنامه‌ها از VPN بروند و کدام دور بزنند |
| 🎨 **[hintهای ارائه‌دهنده](user-guide/provider-hints.md)** | هدرهای `flclashm-*` برای ظاهر و رفتار |

👉 نمی‌دانید از کجا شروع کنید — [مرور راهنمای کاربر](user-guide/README.md) را ببینید.
