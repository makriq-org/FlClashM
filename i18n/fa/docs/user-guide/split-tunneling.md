# 🎯 تونل‌زنی جداگانه

تونل‌زنی جداگانه به پرسشی ساده پاسخ می‌دهد: **کدام برنامه‌ها از VPN بروند و کدام مستقیم**. دو راه برای تنظیم آن هست:

- 🖐 **دستی** — در تنظیمات برنامه؛
- 📄 **از طریق پروفایل** — ارائه‌دهنده قوانین را مستقیم در YAML تعریف می‌کند.

> ℹ️ قوانین پروفایل بر تنظیمات دستی **اولویت** دارند. اگر پروفایل تونل‌زنی جداگانه را تعریف کند، در تنظیمات برنامه نشان داده می‌شود که کنترل دسترسی توسط پروفایل مدیریت می‌شود.

---

## 📄 تنظیم از طریق پروفایل

قوانین در بخش `tun` قرار دارند. دو حالت ناسازگار وجود دارد.

### ✅ لیست سفید — فقط برنامه‌های منتخب

**فقط** برنامه‌های فهرست‌شده از VPN می‌روند؛ بقیه مستقیم.

```yaml
tun:
  enable: true
  include-package:
    - org.telegram.messenger
    - com.termux
```

### ⛔ لیست سیاه — استثنا کردن برنامه‌های منتخب

**همه‌چیز جز** برنامه‌های فهرست‌شده از VPN می‌رود.

```yaml
tun:
  enable: true
  exclude-package:
    - com.android.chrome
    - org.mozilla.firefox
```

> ⚠️ `include-package` و `exclude-package` را **نمی‌توان** هم‌زمان به کار برد.

---

## 🧬 قالب‌های selector

افزون بر نام دقیق بسته، wildcard و عبارت باقاعده پشتیبانی می‌شود:

| قالب | نمونه | معنی |
|------|-------|------|
| 🎯 نام دقیق | `com.termux` | تطبیق دقیق بسته |
| ✳️ wildcard | `*.yandex.*` | همهٔ برنامه‌های Yandex |
| 🔤 regex | `re:^org\.mozilla\..+$` | همهٔ برنامه‌های Mozilla |
| 🚫 استثنا | `!ru.yandex.browser` | حذف از فهرست |

می‌توان آن‌ها را ترکیب کرد — مثلاً «همهٔ Yandex جز مرورگر، به‌علاوهٔ همهٔ Mozilla»:

```yaml
tun:
  enable: true
  exclude-package:
    - '*.yandex.*'              # همهٔ برنامه‌های Yandex
    - '!ru.yandex.browser'      # جز Yandex Browser
    - 're:^org\.mozilla\..+$'   # همهٔ برنامه‌های Mozilla
```

## 📥 فهرست از فایل و URL

فهرست‌های بلند را بهتر است بیرون نگه داشت — هر خط یک نام بسته یا selector.

**از فایل:**

```yaml
tun:
  enable: true
  include-package-file:
    - lists/allowed-apps.txt
```

**از URL روی HTTP(S):**

```yaml
tun:
  enable: true
  include-package-url: https://example.com/packages.txt
```

> 💾 فهرست URL به‌صورت محلی کش می‌شود و اگر آدرس در دسترس نباشد، همان استفاده می‌گردد.

## ⚙️ زیر پوسته چطور کار می‌کند

1. 📖 FlClashM بخش `tun` را از پروفایل می‌خواند.
2. 🔎 selectorها (wildcard، regex) را به بسته‌های نصب‌شدهٔ مشخص تحلیل می‌کند.
3. 🧱 قوانین کنترل دسترسی می‌سازد.
4. 🏆 این قوانین بر تنظیمات دستی اولویت دارند.
