# تونل‌زنی جداگانه

FlClashM به شما امکان می‌دهد کنترل کنید کدام برنامه‌ها از VPN استفاده کنند و کدام نکنند. این کار به دو روش قابل تنظیم است: دستی در تنظیمات برنامه یا مستقیماً در پروفایل YAML.

## تونل‌زنی جداگانه از طریق پروفایل

ارائه‌دهنده می‌تواند قوانین تونل‌زنی جداگانه را مستقیماً در پروفایل تنظیم کند. این قوانین بر تنظیمات دستی کاربر اولویت دارند.

### لیست سفید: فقط برنامه‌های انتخاب‌شده

```yaml
tun:
  enable: true
  include-package:
    - org.telegram.messenger
    - com.termux
```

فقط برنامه‌های فهرست‌شده از VPN استفاده خواهند کرد.

### لیست سیاه: حذف برنامه‌های انتخاب‌شده

```yaml
tun:
  enable: true
  exclude-package:
    - com.android.chrome
    - org.mozilla.firefox
```

برنامه‌های فهرست‌شده از VPN استفاده نخواهند کرد.

> نمی‌توانید `include-package` و `exclude-package` را همزمان استفاده کنید.

## فرمت‌های انتخابگر

علاوه بر نام‌های دقیق بسته‌ها، الگوها و عبارات منظم پشتیبانی می‌شوند:

| فرمت | مثال | توضیحات |
|------|------|---------|
| نام دقیق | `com.termux` | تطابق دقیق |
| الگو | `*.yandex.*` | تمام برنامه‌های Yandex |
| عبارت منظم | `re:^org\.mozilla\..+$` | تمام برنامه‌های Mozilla |
| استثنا | `!ru.yandex.browser` | حذف از لیست |

### مثال با الگوها و استثناها

```yaml
tun:
  enable: true
  exclude-package:
    - '*.yandex.*'              # تمام برنامه‌های Yandex
    - '!ru.yandex.browser'      # به جز مرورگر Yandex
    - 're:^org\.mozilla\..+$'   # تمام برنامه‌های Mozilla
```

## بارگذاری لیست‌ها از فایل‌ها

لیست بسته‌ها را می‌توان در فایل‌های جداگانه ذخیره کرد:

```yaml
tun:
  enable: true
  include-package-file:
    - lists/allowed-apps.txt
```

فایل‌ها باید شامل یک نام بسته یا انتخابگر در هر خط باشند.

## بارگذاری لیست‌ها از URL

لیست‌ها را می‌توان از طریق HTTP(S) دریافت کرد:

```yaml
tun:
  enable: true
  include-package-url: https://example.com/packages.txt
```

لیست به‌صورت محلی کش می‌شود و وقتی URL در دسترس نباشد استفاده می‌شود.

## نحوه کار

1. FlClashM بخش `tun` را از پروفایل می‌خواند.
2. انتخابگرها (الگوها، regex) را به بسته‌های نصب‌شده خاص تبدیل می‌کند.
3. قوانین کنترل دسترسی ایجاد می‌کند.
4. این قوانین بر تنظیمات دستی اولویت دارند.

اگر پروفایل تونل‌زنی جداگانه تعریف کند، تنظیمات برنامه نشان می‌دهد که کنترل دسترسی توسط پروفایل مدیریت می‌شود.
