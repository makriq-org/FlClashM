# Границы совместимости

Этот документ фиксирует остаточные следы старой базы, которые ещё остаются
в `FlClashM` после завершения ребрендинга.

## Что уже переименовано

- Метка приложения, иконки, метки виджетов и идентификаторы каналов уведомлений
- Артефакты релизов и их метаданные
- Репозиторий релизов: `makriq-org/FlClashM`
- Android-пакет для непрерывности: `com.makriq.flclash`
- Документация и примеры действий для пользователей
- Deep link продукта: `flclashm://`
- Заголовки подсказок провайдера: `flclashm-*`
- Тип payload TV-синхронизации: `flclashm_tv_sync`

## Что осталось как техническая совместимость

**Android namespace `com.follow.clashx*`**
Причина: текущая Android-база и генерируемый код всё ещё собраны вокруг этого
source namespace. Это внутренний кодовый слой, а не публичный бренд.

**Старые вспомогательные файлы `flclashx_*`**
Причина: нужны только как вход для одноразового переноса данных в `flclashm_*`.
Новые записи идут только в `flclashm_*`.

## Правило для новых идентификаторов

Если появляется новый публичный идентификатор, он должен называться в стиле
`FlClashM` или `flclashm`.

Если временно остаётся старое имя:

- Оно должно быть явно локализовано в этой границе совместимости.
- Причина должна быть кратко объяснена.
- Оно не должно использоваться как умолчание для новых интеграций.
