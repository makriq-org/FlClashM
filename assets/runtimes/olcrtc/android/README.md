Bundled olcrtc Android executables are generated by:

```bash
dart setup.dart android --out runtime-assets
```

Source: https://github.com/ghostlane-project/olcrtc (proofkit).
The pinned source is built with `tool/patches/olcrtc-vkcalls-media-refresh.patch`.
The patch digest is included in `release.txt`, so changing it invalidates the cache.

The source commit is pinned in `lib/product/runtime/olcrtc_release.dart`.
That contract also pins Go and Android NDK versions used for reproducible builds.
Setup passes `-buildvcs=false`: Git tag availability in a full or shallow checkout
must not change the embedded module version and therefore the binary digest.
Source provenance is recorded in `release.txt` and the pinned SHA-256 values.
The CLI `-version` consequently prints `(devel)` for these bundled executables.
The same file pins the SHA-256 digest of every ABI binary. Setup and tests
reject stale or modified binaries even when `release.txt` still matches.

OlcRTC embeds its default name dictionaries. The generated config leaves the
optional `data` override unset, so no separate runtime data directory is
packaged.
