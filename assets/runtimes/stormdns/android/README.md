Bundled StormDNS Android executables are generated by:

```bash
dart setup.dart android --out runtime-assets
```

The source commit is pinned in `lib/product/runtime/stormdns_release.dart`.
That contract also pins Go and Android NDK versions used for reproducible builds.
The same file pins the SHA-256 digest of every ABI binary. Setup and tests
reject stale or modified binaries even when `release.txt` still matches.

The binary is never downloaded or swapped while the app runs.

StormDNS needs two staged artifacts per node: `client_config.toml` and
`client_resolvers.txt`. Both live in the node working directory; the resolver
file is rewritten by the platform when the physical network DNS changes.

`LICENSE` keeps the upstream MIT notice required for redistribution.
